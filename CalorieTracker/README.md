# سعراتي — تطبيق حساب السعرات (iOS / SwiftUI)

تطبيق بسيط وملوّن لتتبع السعرات والماكروز، مستوحى من Cal AI.

## المزايا
- **مستهدف السعرات**: حلقة دائرية كبيرة مع نسبة الاكتمال والمتبقي.
- **البروتين / الكارب / الدهون**: ثلاث حلقات دائرية، كل واحدة بنسبة اكتمال و(المستهلك / المستهدف).
- **قائمة الوجبات**: أدخل اسم الوجبة + السعرات + البروتين + الكارب + الدهون.
  - اضغط على الوجبة لتعديلها، واسحب لحذفها.
  - زر لحساب السعرات تلقائيًا من الماكروز (4/4/9).
- **الأهداف**: زر 🎯 أعلى الشاشة لتعديل المستهدف اليومي.
- التنقل بين الأيام (السهمين أعلى الشاشة، والضغط على التاريخ يرجعك لليوم).
- البيانات محفوظة على الجهاز، والواجهة بالعربي (من اليمين لليسار).

## التشغيل
1. افتح `CalorieTracker.xcodeproj` في Xcode 15 أو أحدث (على جهاز Mac).
2. اختر Target `CalorieTracker` ← Signing & Capabilities ← اختر حسابك (Team).
   غيّر `Bundle Identifier` إذا لزم (مثلًا `com.yourname.CalorieTracker`).
3. وصّل الآيفون واضغط ▶︎ Run. (يتطلب iOS 16 أو أحدث)
